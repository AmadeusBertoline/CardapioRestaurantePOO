# CardapioRestaurantePOO
Sistema para um restaurante, desenvolvido sob demanda da aula de Programação Orientada a Objetos na Fatec Zona Leste


O sistema deverá permitir a Criação, Atualização, Remoção, Exibição e Listagem do(s) Pratos(s) do restaurante. Este sistema deverá conter uma classe Prato a qual precisará ter as seguintes características e comportamentos. Características : id : long codigo : String nome : String calorias : int preco : double ingredientes : String Comportamentos : String toString() // Deve retornar um texto contendo o nome, calorias e preço do prato boolean equals( Prato outroPrato ) // deverá retornar verdadeiro se o codigo do prato atual for igual ao codigo do outroPrato Crie uma classe chamada GestaoCardapio, contendo as seguintes características e comportamentos. Características: indice : int // Indica em qual posição deve ser guardada a próxima instância de Prato pratos : Prato[] // Matriz com 50 pratos Comportamentos: void criar() void atualizar() void excluir() void exibir() void listar() void menu() Regras da classe GestaoCardapio Crie uma variável de instância para guardar um objeto do tipo Scanner() que será usado posteriormente nos demais métodos. O comportamento criar() deve criar uma nova instância de Prato, preencher as características desta instância com informações fornecidas pelo usuário, e deve guardar esta instância de prato na lista de (pratos) na posição indicada pela variável indice. A função exibir() deve pedir ao usuário para que digite o CODIGO e procure qual prato na lista(pratos) possui um CODIGO idêntico. Os dados do prato encontrado devem ser exibidos na tela. A função excluir() deve pedir ao usuário para digitar um CODIGO, e em seguida deve excluir o(s) prato(s) com este CODIGO da lista (pratos) A função atualizar() deve pedir ao usuário para digitar um CODIGO, e em seguida deve procurar pelo primeiro prato na lista (pratos) que contenha este CODIGO. A função deve em seguida solicitar ao usuário para que digite os demais dados do prato (nome, calorias, preco e ingredientes) para trocar os valores das características do prato encontrado na lista pelos valores recém informados pelo usuário. O método menu() deve rodar em um loop infinito, mostrando na tela as opções para o usuário: (C)riar (E)xibir (R)emover (A)tualizar (L)istar (S)air Pegue a primeira letra digitada pelo usuário e assuma como sendo a opção escolhida String textoMaiusculo = <objeto Scanner>.nextLine().toUpperCase(); char letra = textoMaiusculo.charAt(0); Conforme a opção escolhida o método deve invocar a função correspondente criar(), exibir(), excluir(), atualizar() ou System.exit(0) para sair do sistema.
